# Estructura del reporte final

## 1. Portada

- Proyecto: [NombreProyecto]
- Curso: [nombre_curso]
- Integrantes: [nombres]
- Docente: [nombre_docente]
- Fecha: [aaaa-mm-dd]
- Version documento: [vX.Y]

## 2. Resumen ejecutivo

- Objetivo de pruebas.
- Alcance cubierto (Login, Maestro, Transaccional).
- Resultado general (aprobado/parcial/no aprobado).

## 3. Contexto y alcance

- Sistema bajo prueba.
- Ambientes usados.
- Fuera de alcance.

## 4. Estrategia y metodologia

- Tipos de prueba aplicados.
- Herramientas usadas.
- Criterios de entrada y salida.

## 5. Criterios de aceptacion

- Referencia a [01-planificacion/criterios-aceptacion.md].
- Trazabilidad criterio -> caso de prueba -> evidencia.

## 6. Ejecucion de pruebas

### 6.1 Unitarias (JUnit 5)
- Total ejecutadas: [n]
- Exitosas: [n]
- Fallidas: [n]
- Evidencia: [ruta]

### 6.2 Funcionales
- Total ejecutadas: [n]
- Exitosas: [n]
- Fallidas: [n]
- Evidencia: [ruta]

### 6.3 API (Postman)
- Total requests probadas: [n]
- Exitosas: [n]
- Fallidas: [n]
- Evidencia: [ruta]

### 6.4 Base de datos
- Integridad: [resultado]
- Transacciones: [resultado]
- Evidencia: [ruta]

## 7. Defectos encontrados

- Resumen por severidad.
- Top 5 defectos relevantes.
- Estado actual de cada bug.

## 8. Riesgos residuales

- Riesgo 1: [descripcion]
- Riesgo 2: [descripcion]
- Mitigaciones propuestas.

## 9. Conclusiones

- Nivel de calidad alcanzado.
- Recomendacion de salida a produccion (si/no/condicional).

## 10. Anexos

- Reportes de pruebas.
- Capturas de pantalla.
- Scripts SQL ejecutados.
- Coleccion Postman exportada.
- Videos (screencast y presentacion).
