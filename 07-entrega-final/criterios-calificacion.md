# Criterios de calificacion

Tabla de referencia para autoevaluacion previa a entrega.

| Criterio | Peso sugerido | Condicion de cumplimiento |
|---|---|---|
| Fase 1: Planificacion y criterios | 15% | Plan completo y criterios trazables al sistema real |
| Fase 2: Unitarias JUnit 5 | 20% | Minimo de pruebas, ejecucion y evidencia |
| Fase 3: Funcionales Selenium IDE | 20% | Casos ejecutados + suite + capturas por caso |
| Fase 4: API Postman | 15% | Coleccion, tests pm.test y reporte HTML |
| Fase 5: Base de datos | 15% | Scripts adaptados + evidencia de integridad y transacciones |
| Fase 6: Seguridad ZAP | 10% | Escaneo, reporte y analisis de alertas |
| Entrega final y calidad de evidencia | 5% | Reporte final, videos y coherencia de commits |

## Reglas de penalizacion alta

- Artefacto sin relacion con el proyecto real.
- Evidencia no verificable.
- Placeholder sin reemplazar en entrega final.
- Imposibilidad de demostrar artefacto en vivo.
